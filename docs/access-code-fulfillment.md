# 0.99 元兑换码交付说明

> 适用版本：40 题首发版（`40q-v1`）  
> 更新：2026-11-12

## 1. 生成兑换码

```bash
cd server
npm run access:codes -- --count 100 --batch xhs-2026-11 --max-redemptions 3 --days 180
# 默认生成 5 位纯数字码（如 82417，对标店铺 4-5 位验证码习惯）；--style alnum 可回退旧长码
```

生成结果：

```text
server/access-codes/xhs-2026-11-<timestamp>.csv
```

CSV 字段：

```text
code,batch,maxRedemptions,expiresAt
82417,xhs-2026-11,3,2027-05-11T...   ← 5 位纯数字，不以 0 开头
```

`server/access-codes/` 已加入 `.gitignore`，**不要把兑换码 CSV 提交到仓库或公开网盘**。

### 2.2 三处绝对不能抄

|---|---|---|
| 「复制到浏览器，即可开始测试」 | 明确诱导跳出站内浏览器，属导流话术 | 「点击上方链接，页面会自动兑换」 |

## 3. 兑换逻辑

- 商品：小红书店铺「81 型人格 40 题完整测评」0.99 元；
- 兑换码在服务端 `AccessCode` 表校验；
- 兑换成功生成本机 `AccessGrant` 令牌，保存在浏览器 `localStorage`；
- 令牌可解锁 **40 题测试 + 完整报告全部内容**；
- 不再要求邮箱、分享海报、打赏或二次付费；
- 默认每码最多 3 次兑换，有效期 180 天。

## 4. 售后处理

| 情况 | 处理 |
|---|---|
| 兑换码无效 | 检查空格/大小写；确认批次和有效期；必要时补发新码 |
| 兑换码次数用尽 | 根据订单号补发新码，旧码在后台禁用 |
| 用户换设备 | 让用户重新输入同一码（未超过 3 次）；超过则补发 |
| 测试中断 | 测试进度保存在浏览器 localStorage；清缓存会丢失，需重新作答 |
| 站点故障 | 先补发/延期，不要让用户重复付费 |
| 退款 | 按小红书平台规则和商品页公示政策处理，保留订单记录 |

## 5. 禁用/轮换

直接更新 `AccessCode.disabled = true` 即可停止某个码。  
如果整批码泄露，生成新批次并停用旧批次；不要在公开笔记/评论里发布兑换码 CSV。
