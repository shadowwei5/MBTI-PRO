## 8. 本轮新增踩坑记录（下次别再踩）

1. **本机 TUN 代理会掐断 SSH**：`yushe-mihomo` 只有一个香港节点，其出口 IP 被目标服务器 fail2ban/防火墙拦截，表现为 TCP 连上后**在 banner 交换前被 close**（`kex_exchange_identification: Connection closed by remote host`），极易误判为"服务器 sshd 故障"。解法：通过 mihomo API 临时切 `mode=direct`
   （`PATCH http://127.0.0.1:9090/configs {"mode":"direct"}`）走家宽出口，用完切回 `rule`。
2. **DNS 会被本地代理 fake-ip 劫持**：`Resolve-DnsName` / `nslookup <权威NS>` 都返回 `198.18.x.x`，必须用 **DoH**（`https://cloudflare-dns.com/dns-query?name=...&type=A`）才能读到真实记录。
3. **Cloudflare 面板可以直接复用浏览器登录态调内部 API**：`page.fetch('/api/v4/zones/...')` 可读**灰云/橙云记录背后的真实源站 IP**，不必登录腾讯云控制台翻实例。
4. **腾讯云控制台表格是懒加载**：域名列表初次读取为空，等 9 秒后才有数据——不要据此判断"账号里没有资源"。
5. **GitHub 网页表单提交会 422（"You can't perform that action at this time"）**：更新已有 Secret 反复失败，但**新增 Secret 的路径可用**。绕法：新增一套名字（如 `DEPLOY_*`）并改 workflow 引用，而不是去改旧 Secret。
6. **OrcaTerm 网页终端里 `keyboard.paste` 会只留下 `^M`**：改用 `keyboard.type` 逐字符输入；长命令用 base64 传输（`echo <b64> | base64 -d > f && bash f`）最稳。
7. **PowerShell 管道给 ssh 会带 CRLF**，导致 `$'\r': command not found` 或路径尾部多出 `\r`。改为把脚本 base64 编码后单行传输。
8. **Windows PowerShell 5.1 用 `-File` 执行 UTF-8 无 BOM 的 .ps1 会把中文读成乱码并破坏引号**：运维脚本一律写纯 ASCII。
9. **本机 ssh 客户端不在 PATH**：用 `C:\Program Files\Git\usr\bin\ssh.exe`（scp 同理）。
