**证据 1：发布页「智能推荐」三项全部不可选**
```
课件/教案/手抄报(未开通)        cursor: not-allowed  颜色 rgba(0,0,0,0.2)
PPT/简历/其他模板(未开通)        cursor: not-allowed  颜色 rgba(0,0,0,0.2)
企业人力资源/市场营销/职业规划(未开通)  cursor: not-allowed  颜色 rgba(0,0,0,0.2)
```
平台识别出这商品属于「课件/模板」类，但个人店**未开通**。

**证据 2：一级类目里点「电子资源」→ 二级类目「暂无内容」**
发布页一级类目确实列出「电子资源」，但点进去后二级/三级/四级类目全部显示「暂无内容」——说明个人店在该大类下没有任何已开通子类目。

**证据 3：类目选择器里「电子资源」被归入邀约分组**
新增类目 → 类目选择器底部原文：
> **「电子资源 / 平台邀约类目｜需提报资料审核，可参考邀约类目规则，点击自荐提报」**

同时类目资质管理页「可售类目列表」为 **共 0 条**——个人店目前一个类目都没开通。

### 结论
「电子资源」不是普通可售类目，而是**平台邀约类目**，需提报资料审核或走「自荐提报」。这与公开资料一致：电子资源类目要求**粉丝 ≥1000、笔记 ≥30 篇、月流水 ≥6000**（你的账号现在：3 粉丝、4 篇笔记）。

## 三、三条可选路径（需要你定）

### 路径 A：先上架「非虚拟」类目，把链路跑通（我建议先做这个）
个人店已开通的类目是实物类（食品、3C、家居、服饰、美妆、母婴、汽车用品、生活服务、文化办公、运动户外、票务等）。

**做法**：把「兑换码」做成**实物卡/明信片**形态，类目选「文具电教/文化用品」或「生活服务」。小红书允许「实物 + 权益卡」，发货走物流或自提。
- 优点：立刻能卖，链路今天就能通
- 缺点：要寄实物（或设成无需物流），0.99 元 + 邮费不经济
- 变体：标价 0.99，设为「虚拟发货/无需物流」，但类目仍是实物类——**存在被判「类目错放」的风险**

### 路径 B：走「自荐提报」申请电子资源类目
类目选择器里「电子资源」旁有**「点击自荐提报」**，但实测点了之后**只跳到类目选择弹窗，没有出现申请表单**（该入口目前是提示文案，不是可提交表单）。
- 优点：正规、长期稳定、可自动发货
- 缺点：入口未真正开放；且公开规则要求粉丝 ≥1000、笔记 ≥30、月流水 ≥6000，账号 3 粉丝大概率不受理

### 路径 C：办个体工商户执照，升级个体店
后台有现成入口：**`/app-seller/update-store/shop-type`（店铺升级）**，类目选择弹窗里也直接写了「若当前店铺类型不支持售卖您所需的类目，可操作**店铺升级**」。
- 优点：最彻底，个体店类目比个人店宽，可申请电子资源/教育部分子类
- 缺点：需先办执照（3–14 天），期间无法上架

### 路径 D：先不卖，把内容做起来
先用日更笔记涨粉到 1000 + 30 篇，再回来申请电子资源类目。
- 优点：0 成本、符合平台规则、顺便积累内容资产
- 缺点：慢

## 六、技术备注（下次接手用）

| 坑 | 解法 |
|---|---|
| 所在地区是 **4 级级联**（省/市/区/街道），不是 3 级 | 逐列点选，最后一列选完才回填；列容器需先 `scrollTop` 把目标滚进面板可视带 |
| 级联对 `.click()` 无反应 | 必须用 `page.mouse.click` 真实坐标，且坐标要在 `.d-cascader-dropdown` 可视范围内 |
| 身份证上传控件 | 隐藏 `input[type=file]`，用 `DataTransfer` + `File` 注入并 `dispatchEvent(change)` |
| 商品图上传 | 走「选择图片」素材库弹窗，`上传本地图片` 不再弹系统选择器，而是页内「本地上传」面板里的隐藏 input |
| 商品标题 | **必须 16–60 字符（8–30 汉字）**，文档里的 15 字定稿不达标，会报错 |
| 商品创建页 | 默认是「以图发品」，要点「切换普通发品」才有标准表单 |
| 截图 | 该站 `Page.captureScreenshot` 频繁超时，改用纯 `evaluate` 读 DOM |
