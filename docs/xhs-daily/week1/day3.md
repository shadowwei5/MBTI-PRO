## 正文（直接复制）

```
上周测出 ENFP，这周变成 INFP。不一定是题库坏了。

题目问的是「平时」，可你平时不止一种状态。聚会里你愿意主动认识人，加班那周你更想按流程和细节把事情做完——两次都是真话，只是被问到的场景不同。

传统 16 型在每个维度上设一条分界线，分数差一两分就会被推到另一端。81 型把每一维拆成三档，边界附近的人有地方可落：3×3×3×3，一共 81 个坐标。

40 题里有一道正好在问这个维度：「我做事注重细节和具体步骤，相信“眼见为实”」对「我关注事物背后的整体图景和规律，相信直觉的指引」。两栏都能选，也可以停在中间。

所以「测出来会变」未必是测评不准，也可能是坐标系太粗。这个坐标最耐人寻味的参照是卡卡西：平时总迟到、一个人看书，带队的任务里却能在几步之前预判对手；算得清局面，也护得住同伴。安静和控场、推演和体谅在他身上同时成立，硬把他归到某一端，多少有点可惜。

你换过几个结果？

本内容仅供自我探索与娱乐参考，不构成心理诊断、医疗建议或招聘依据。MBTI-PRO 与 MBTI 官方机构无关联。
```
