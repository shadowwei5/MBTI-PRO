## 二、Day2 掉的主因：标题用了产品内部编码

**实测到的差异**：我交付的标题是「钢铁侠是J人还是P人」，你实际发的是「钢铁侠到底是**ENTJ还是ENTP**？」。

**平台自己的证据**：Day2 笔记前台「猜你想搜」显示 **「漫威mbti」** —— 这是小红书内部的联想词。平台把这类内容挂在 `mbti` 这个流量词下，**不是**挂在 ENTJ/ENTP 下。

**后果**：
1. 搜「漫威 mbti」的人**根本搜不到** Day2；
2. 读者看到 ENTJ/ENTP 两个缩写，**不知道是什么**，直接划走；
3. 「J人」「P人」是站内高频词，Day2 标题里一个都没有（连 `#J人` 标签也漏了）。

**这正是我在做 Day3 时定的第一条规则**：标题只允许出现平台口语词（J人/P人/16型/人格测试/MBTI），**禁止** ENTJ/ABCD 这类编码。

### 从样本里读出的四条硬规律

**规律 1：标题里出现的是「J人」「P人」「16型」，不是 ENTJ/INTP**
「J人」「P人」「E人」「I人」是站内约定俗成的口语词；四字母编码只有老玩家会用。**新读者占绝大多数**。

**规律 2：「测试」「对号入座」「你是哪一种」是强钩子**
2088 赞的「测试：你是J人还是P人」、2253 赞的「你是MBTI里的哪一种人格✨来对号入座」——都是**直接把测试放在标题里**，用户预期「点进来能测」，点击率天然高。

**规律 3：正文要给「互动指令」，而不是给结论**
拆开 2253 赞那篇，正文最后一句是：
> ✨**评论区留下你的MBTI四个字母，找找同频的小伙伴～**

**规律 4：评论区的互动形式是「打字母」**
实测 2088 赞那篇的评论：
```
用户已注销 | JPJPJ
枫游京       | ppjpj
加油麦菜菜   | jjjjj@点点
一团小吃货   | 图125是j剩下的是p，请问我到底是j还是p？
```
**全是字母**。这就是 Day2 我加 P9 三选一投票框的依据——方向是对的，只是 Day2 标题把流量入口堵死了。

## 四、Day3 重新设计

### 选题：换人（宇智波鼬 → 曾国藩）

| | 原选题 宇智波鼬 | 新选题 曾国藩 |
|---|---|---|
| 站内热度 | 单独搜「宇智波鼬」最高 5298 赞（且是手势图） | 搜「曾国藩」**1.5 万赞**（普通人逆袭/模仿曾国藩） |
| 产品契合 | INFJ，中间隔着一层 | **ABCD 全能者型**，四维全居中 = 产品核心差异点 |
| 与前两篇重复 | 动漫人物 | **真实历史人物**，差异化 |
| 争议强度 | 冷血 vs 深情（较常见） | 狠 vs 软（家书原文可证，可信度高） |

### 标题（16 字，一字不改地用）

```
曾国藩这种人格，16型真的装不下
```

- 「16型」= 站内高频词，占住「MBTI最恐怖第一名：INFJ」这类标题的同一个流量池；
- 「人格」= 另一个高频词；
- 「真的装不下」= 反直觉钩子（爆款「INTJ的高阶目标，从不是无情，是无相」是同款结构）；
- **不含任何内部编码**。

### 正文（328 字，9 段）

关键改动：
1. **第一行就是钩子**：「曾国藩这种人，16 型真的装不下。」——不靠封面兜底；
2. **不放「第 X 张图」**（Day2 的原句「第 7 张图是原题」要求用户必须点开图才能看懂文案，是负担）；
3. **最后一行是明确的互动指令**：「评论区打一个字母：T / C / F」；
4. 狠 / 软两段**各自有可验证的事实**（治军用军法、日记里骂自己去看行刑）。

### 9 图结构（3 张强视觉）

| 页 | 内容 | 改动 |
|---|---|---|
| P1 封面 | **曾国藩大字** + 右侧 **ABCD 人格画像** + 「狠了一辈子 / 却没几个人懂他」+ 底部产品信息条 | ⭐ 新增封面视觉锤 + 信息条 |
| P2 | 争议：「他是冷血的狠人，还是菩萨心肠？」+ T/C/F 三档 | 修正了「E、N、J 没争议」的表述错误 |

| P4 | 软的那一面 + **日记原文引用**「旷日荒谬至此，尚得为人乎？」 | ⭐ 新增引文块 |

| P7 | 原题 #83（正方/反方）+ 四维坐标条 | — |

### 顺手修掉的两个错

1. **P8 原写「虚构角色 · 仅作性格类比」** —— 曾国藩是真人。已改为「真实历史人物 · 仅作性格类比 / 不构成对其人格的评价或定论」。
2. **P2 原写「16 型只能二选一」** —— 81 型在这一维是**三档**（T/C/F）。已改为「16 型在这一维二选一 · 81 型留了中间档 C」。

### 你指出的最大冲突：正文说 ABCD 装不下，05 图却说「另外三维没争议」

**这是结构性的错误，不是措辞问题。**

原因：Day3 原来的 9 图结构是为「端值型」设计的——比如钢铁侠 ENTD，三维落在端值、只有一维卡中间，所以可以说「另外三维没争议，争议全在第 04 维」。我换人物时只改了名字和类型码，**把这个「单维争议」结构原封不动套给了四维全居中的曾国藩**，于是出现：

- 正文说他是 ABCD（四维全居中，16 型装不下）
- 05 图却说「另外三维没争议」（= 只有一维有争议 = 他是端值型）

**两者逻辑上不可能同时成立。**

修正后的口径（全文统一）：

| 位置 | 改前 | 改后 |
|---|---|---|
| P2 说明 | 「争议不在他是谁，在第 03 维」 | 「他的四个维度全部落在中间——不是某一维卡住，是每一维都到不了两端」 |
| P5 标题 | 「另外三维没争议」 | 「**另外三维，也卡在中间**」 |
| P5 内容 | 「E 不必争 / N 不必争 / J 不必争」 | 「能量来源：独处能干活，见人也能聊；认知方式：靠一件件具体的事磨出判断；生活态度：作息几十年不改，打法却随时调整」 |
| P6 结尾 | 只讲第 03 维 | 加「而他不止这一维居中——四个维度全部落在中间，这才是 16 型装不下他的真正原因」 |
| P6 脚注 | 「第 03 维就是这次的争议点」 | 「四个维度全部落在中间 · 这次展开讲的是第 03 维」 |
| 正文 | 只提 C 档 | 加「他不只是这一维卡在中间——四个维度全部落在中间。16 型给他找不到一格，81 型给他留了一整格」 |
| P7 坐标条 | 只画 3 条、写死高亮中间档 | **画满 4 条、数据驱动高亮**——四条维度的中间档（A/B/C/D）全部标红，一眼看出「四维全居中」 |

**同时新增了全文一致性校验脚本**，规则包括：
- 全居中型不得出现「其他三维没争议」；端值型必须有无争议锁定句
- 全居中型正文必须点出「四维全居中」
- 标题必须含平台口语词、禁止内部编码、禁止图序指引（Day1/2 已发布不追溯）
- 真人必须有 `fictionNote`；投票框必须与争议维一致；dims 落点拼出的字母必须等于类型码

**Day3 校验结果：0 错误 0 提醒。Day4–7 标题顺带修正**（都有和 Day2 一样的「无平台口语词」问题，未发布正是改的时机）：

| 篇 | 改前 | 改后 |
|---|---|---|
| Day4 路飞 | 路飞靠眼睛，还是靠直觉 | 路飞是**S人还是N人**？他自己也没想过 |
| Day5 柯南 | 柯南是台前型，还是幕后型 | 柯南是**E人还是I人**？判若两人 |
| Day6 L | 《死亡笔记》的L到底有没有计划 | **L是J人还是P人**？局算尽饭点没准 |
| Day7 赫敏 | 赫敏到底算不算外向 | 赫敏是**E人还是I人**？最吵最静都是她 |
