## 2. 文件结构

```text
docs/xhs-daily/week1/
├── README.md            ← 本文件
├── review.html          ← 7 天审核台（单文件，浏览器打开，可逐天审核并导出反馈）
├── day1.md … day7.md    ← 每天可直接复制的发布文案
├── day1/01.png … 09.png
├── …
└── day7/01.png … 09.png
```

模板与渲染脚本：

```text
docs/xhs-daily/template/cards.html        （NOTE_LIBRARY 含 day1-day7 + elon）
scripts/xhs-daily/render-cards.mjs       （批量出图）
scripts/xhs-daily/build-review.mjs       （重新生成审核台）
```

**审核台用法**：浏览器打开 `review.html` → 顶部 D1–D7 逐天切换（也可 ← → 键）→ 文案可一键复制、图片点击放大 → 每天标记「通过／需修改／待定」并写备注 → 结论自动存本机浏览器 → 点「导出审核结果」下载 JSON 交给助手逐条修改。文案或图片更新后运行 `node scripts/xhs-daily/build-review.mjs` 重建即可。

复现 / 重出图：

```bash
cd H:/ccwork/MBTI-PRO
node scripts/xhs-daily/render-cards.mjs --all
node scripts/xhs-daily/render-cards.mjs --note day3 --out docs/xhs-daily/week1/day3
```

- **P8 人物卡**：卡片顶部新增一行作品名（《死亡笔记》），下面是名字，再下面是身份（名侦探）。三段式，和档案卡的读法一致。
- 名字长度变了，`nameCls` 的字号分档复核过：2–3 字名字占 76px 档，卡内不空、不挤。
