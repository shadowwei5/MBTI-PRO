## 正文（直接复制）

```
81 型里，钢铁侠（托尼·斯塔克）这种「框架稳、路径随便改」的人，正好卡在 J 和 P 中间。发布会不按稿子讲，方案当场推翻，战甲却从 Mark I 排到了几十代。

E、N、T 三维在他身上几乎不用争。争的是最后一维：他到底是计划型（J），还是随时改（P）？

像 J 的地方很硬：改哪一代、先改什么、下一版什么时候上，全排得清清楚楚；公司、议程、对外口径，也都在他手里。
像 P 的地方也很硬：刚定下的方案，现场就能推翻；发布会不按稿子讲；承诺过的路线，说换就换。

所以他不是 J，也不是 P。他是「框架稳、路径随便改」——大方向不轻易动，怎么走到那儿随时改。这一档 16 型里没有，81 型把它单独放在中间，叫 D。

整套 40 题，约 6–8 分钟，做完会告诉你在 81 格里落在哪一格。前面那几道只是让你先感受一下题目长什么样。

在评论区打出你的 3 个字母，然后 @点点，她会给你一段专属分析。

你是哪一种？先在 J、D、P 里选一个，再往下看第 9 张。

本内容仅供自我探索与娱乐参考，不构成心理诊断、医疗建议或招聘依据。MBTI-PRO 与 MBTI 官方机构无关联。
```
