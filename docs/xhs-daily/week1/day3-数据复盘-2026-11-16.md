## 三、一个更重要的发现：浏览不是单调下降，是「内容类型决定」

之前我判断「浏览单调递减 = 账号权重下降」。这个判断**也是错的**。真实曲线是：

```
Day1 鸣人    77  ← 人物 + 争议 + 长标题（"漩涡鸣人是直觉型的N人，还是经验型的S人？"）
Day2 钢铁侠  62  ← 人物 + 争议 + 编码标题
Day3 曾国藩  22  ← 人物 + 全居中争议（罕见概念）
Day4 路飞    13  ← 人物 + 争议 + 9图结构
Day5 柯南     2  ← 人物 + 争议 + 海报封面（刚发1小时）
```

### 关键对照

| 篇 | 浏览 | 标题里有「你」吗 | 标题是二选一吗 |
|---|---|---|---|
| Day1 | **77** | **有**（漩涡**鸣人**…还是…） | 是（N 还是 S） |
| Day2 | **62** | **有**（**钢铁侠**…还是…） | 是（J 还是 P） |
| Day3 | 22 | 无（曾国藩**这种人格**…） | 否（"装不下"） |
| Day4 | 13 | 无（**路飞**…他自己也没想过） | 是（S 还是 N） |
| Day5 | 2（1小时） | 无 | 否 |

**Day1/Day2 是全系列唯二标题带「你」或直接对话式提问的两篇，也是唯二破 60 的。**

这和爆款标题公式完全吻合——公式库 **#21–25 身份代入型**：「说的就是我」「测测你」。我们的 Day3–Day5 标题全部退化成「**XX 的性格，在81型里是哪一格**」，是**产品视角**而不是**读者视角**。

### 所以真正的因果链是

```
标题从「读者视角」退化成「产品视角」
  → 目标人群从「想了解自己的人」缩到「已经在研究 MBTI 的人」
  → 流量池缩小一个数量级
  → 浏览暴跌
```

**这比「账号权重」更可解释，也更可修复。**

## 四、Day5 已经发布了，但用的是「半成品」

Day5（11-17 20:08）用的是**海报封面 + 新标题 + 3 道题**，但有两个问题：

### 问题 1：置顶评论还是旧话术

前台抓到的置顶评论是：
> 「我先来：幕后推完，台前只说结论。」

这是**作者自己给答案**的旧话术，与新的「打 3 个字母 + @点点」机制完全无关。等于把互动入口堵死了。

### 问题 2：正文里没有 @点点（Day4 也没有）

Day4 前台正文仍是：
> 「你是 S 人还是 N 人？评论区打一个字母：S / B / N。」

——这是**改动前**的版本，说明 Day4 发布时用了旧文案。@点点 机制只在 Day5 之后的本地素材里存在。

**所以 Day4/Day5 都无法验证「@点点」机制**，判定 4 未通过是因为机制根本没上线，不是机制无效。

## 五、给 Day6（明天）确定的动作

### 🔴 动作 1：标题改回读者视角（最高优先级）

Day6（L）当前标题：`L这种性格，在81型里是哪一格`
问题：单字母「L」对没看过《死亡笔记》的人无吸引力，且是产品视角。

**新标题（14 字）：`你是不是那种，算到极致却从不守时的人`**

依据公式 **#24（指出特征）**——直接描述一种行为状态，让符合的人立刻代入。避开了「L」这个冷门符号，也避开了「81型」这个产品词。

备选：
- `别人在守计划，他在改计划`（公式 #52 VS 对比型，11 字）
- `敢不敢测，你是守计划还是改计划`（公式 #72 互动测试型，15 字）

### 🔴 动作 2：置顶评论改成引导 @点点

**必须换成**：
```
我先来：A。目标算到极致，过程随它去。
你也可以打出 3 个字母，@点点 会给你一段专属分析。
```
理由：作者自己给答案 = 读者没有开口的理由。爆款的评论区全是 `cabcd` + `@点点`。

### 🔴 动作 3：发布后 10 分钟内，自己先发一条「示例评论」

Day5 的评论区现在只有置顶一条，读者没有跟随示范。可以自己补一条评论：
```
示例：A A C
```
读者看到有人已经打了字母，跟随成本会大幅降低。

### 🟡 动作 4：正文里保留 @点点，但**不要**说「打出 3 个字母」

正文改成：
> 「先做 3 道题，记住你的 3 个字母。评论区打出来，@点点 会给你一段专属分析。」

### 🟢 动作 5：封面沿用 Day5 海报版

Day5 海报封面目前只有 2 小时数据，还不能判断好坏，但结构上符合拆解结论（主文案占宽 70%+、封面上直列三档结果）。Day6 沿用同一结构，**保持变量单一**，只改标题和话术。

## 七、一句话结论

**不是账号权重问题，是标题问题。**

Day1（77）和 Day2（62）之所以好，是因为标题在**和读者说话**（"漩涡鸣人是…还是…"、"钢铁侠是J人还是P人"）。Day3 之后标题变成了**在介绍我们的产品**（"XX的性格，在81型里是哪一格"）。

明天优先只改一件事：**把标题换回读者视角。** 其他保持不变，这样如果 Day6 浏览回到 60+，就坐实了标题是主因。
