## 正文（直接复制）

```
不推演大道理，靠眼前这一拳做判断。E、F、P 三维在路飞身上口径很清楚。

唯独第二维一直有人不服：他靠的是眼睛，还是那种说不清的直觉？

说他像 S：讲原理他听不懂，只能靠身体一遍遍练。眼前这一拳、这一顿饭，就是他全部的信息来源。
说他像 N：他从没调查过谁的底细，见一面就决定信不信这个人——后来发生的事，往往证明他第一眼是对的。

他不是不思考，是思考在前一秒就做完了，剩下的全是行动。81 型在这一维留了 B：不推演，但也不只看眼前，靠的是一种被经验磨出来的整体判断。这种判断说不清，却常常准。

40 题里有一道正对着这里：「做决定时，我主要依据过去的经验和已知的事实」对「做决定时，我常常相信自己的直觉和对未来的预感」。

你更信经验，还是更信直觉？

本内容仅供自我探索与娱乐参考，不构成心理诊断、医疗建议或招聘依据。MBTI-PRO 与 MBTI 官方机构无关联。
```
