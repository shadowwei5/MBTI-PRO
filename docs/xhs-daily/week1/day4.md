## 正文（直接复制）

```
朋友倾诉时你能接住情绪，转身又能把问题拆成几条可执行的步骤。讲道理和讲感受，不一定是二选一。

16 型的 T/F 要求你选一边：要么优先逻辑和客观利弊，要么优先对人的影响和大家的感受。81 型在中间留了一档 C。

C 不是和稀泥。三个具体表现：先安静听完，不急着给方案；重逻辑的人觉得你说得清楚，重感受的人愿意继续往下说；偶尔被说「太冷静」，其实是共情之后还会多想一步。

40 题里有一道：「做决定时，我优先考虑逻辑分析和客观利弊」对「做决定时，我优先考虑对人的影响和大家的感受」。很多人两边都用过，只是场合不同。

我们把它记成坐标，不记成「不够理性」或「不够温柔」。换成一个人可能更好懂：IBCD「内省者型」档案里配的是李冰。都江堰用鱼嘴、飞沙堰、宝瓶口把岷江变成一套运行两千多年的系统——不偏执于堵，也不放任于疏，两种信息都得留住。

你先接情绪，还是先拆问题？

本内容仅供自我探索与娱乐参考，不构成心理诊断、医疗建议或招聘依据。MBTI-PRO 与 MBTI 官方机构无关联。
```
