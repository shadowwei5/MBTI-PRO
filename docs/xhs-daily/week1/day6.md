## 正文（直接复制）

```
《死亡笔记》里的 L 几乎不露面，靠抽象假设和概率推演逼近真相。I、N、T 三维在他身上没什么可争的。

争的是最后一维：他到底是把局算尽了，还是根本没什么计划？

像 J：整场对决的每一步都提前布好——谁去查、哪一步设套、什么时候收网，连自己会怎么死都算进去了。
像 P：作息、吃饭、坐姿全无规律；案情一变就整盘重排，从不守昨天的方案。

他把「目标」算到了极致，把「过程」完全放掉了。16 型只能在 J 和 P 里选一个，所以他要么被写成控制狂，要么被写成邋遢天才。81 型的 D 档，把这两件事分开算。

40 题里有一道正对着这里：「我喜欢列清单，并享受逐一勾选已完成任务的成就感」对「我喜欢凭感觉行事，而不是被清单和计划所限制」。

你是算目标的那种，还是算过程的那种？

本内容仅供自我探索与娱乐参考，不构成心理诊断、医疗建议或招聘依据。MBTI-PRO 与 MBTI 官方机构无关联。
```
