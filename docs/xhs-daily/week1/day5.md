## 正文（直接复制）

```
有的人一到现场就接管局面，问谁、查哪、下一步做什么，全由他开口安排；可一回到家，就像隐形人，一句话都不想说。

这不是忽冷忽热，也不是社恐。这是能量来源落在了「中间」——现场充电，独处放电。

柯南就是这样的人。16 型只能给他 E 或者 I，所以他一直被写成「外向的侦探」。

像 E：场面一乱他就开口，从不等人；该问谁、该查哪，一句话就把所有人调动起来。
像 I：平时缩在角落，把结论借别人的嘴说出来；最关键的推演，永远是一个人做完的。

81 型的 A 档就在中间：社交电量够用，但真正的工作必须独处完成。这不是折中，是两个都真。

整套 40 题，约 6–8 分钟，做完会告诉你在 81 格里落在哪一格——是端值，还是中间。

```
