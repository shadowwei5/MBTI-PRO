## 一、为什么必须换结构（不是优化，是换赛道）

已发 5 篇（Day1–5）**全是「讲人格争议」科普**，从不让读者动手。后果链条已验证：

```
读者不答题 → 不知道结果 → 不评论 → 系统判定低质 → 降流量
```

爆款的评论量是点赞的 **4–9 倍**（如「测测你前世是哪种妖怪」赞 2822 / 评 2.6 万），评论区全是 `cabcd` + `@点点`。**读者答完题，互动成本才降下来。**

## 二、7 图结构

| 页 | 内容 | 与角色型的差异 |
|---|---|---|
| **P1** | 封面：问题式钩子 + **三档结果直接列出** | 角色型是角色名大字 |
| **P2** | 第 1 题（双极题 + A/B/C 选择圈） | 角色型 P2 是「争议」 |
| **P3** | 第 2 题 | 新增 |
| **P4** | 第 3 题 | 新增 |
| **P5** | **结果对照表**：你的 3 个字母 → 属于哪一档 | 角色型 P5 是「结论」 |
| **P6** | 角色锚点：这个角色属于哪一档 | 角色降级，从主角变成素材 |
| **P7** | 打出 3 个字母 + @点点 拿分析 | 同 |

**核心不是「题在第几张图」，而是「读者能在图上当场做完并拿到结果」。**

P5 的对照表 = 之前做废的「坐标条」的正确用法：
- ❌ 旧坐标条：81 型产品的四维坐标（读者看不懂，与自己无关）
- ✅ 新对照表：**读者自己的 3 个字母 → 结果**（与自己有关，可存可对照）

## 三、Day8 实例数据

**标题**（17 字，公式 #26 数字锚定 + 结果承诺）：
```
回完消息要缓半小时的人，其实分三种
```

**三道题**（全部取自 `server/src/seed.ts` 的 40q-v1 题库，编号与 `short-form.ts` 首发清单一致）：

| 题 | 原题 # | 维度 |
|---|---|---|
| 1 | #1 | E_I 能量来源 |
| 2 | #6 | E_I 能量来源 |
| 3 | #20 | E_I 能量来源 |

**结果对照表**（`resultMap` 字段，3 档）：
```
E → 你是 E：现场就开口
A → 你是 A：看场合切换
I → 你是 I：先观察再融
```

**角色锚点**：柯南（ENTJ），说明「同一种能量，在这个人身上是这样的」。

## 五、复制到下一篇的做法

1. 选一个**人们关心的问题**（不是角色名）
2. 从 `seed.ts` 里挑同一维度的 3 道题（id 必须在 40q-v1 首发清单内）
3. 写 `resultMap`：3 档结果 + 每档一段解释
4. 挑一个**该维度最典型的角色**做 P6 锚点
5. 标题用公式 **#24（指出特征）** 或 **#26（数字锚定）**，必须描述读者状态、不能出现产品词

**选题池**（从站内爆款反推）：
- 社交能量（E/I）← Day8 已做
- 决策方式（T/F）：你会不会为「不公平」生气
- 生活态度（J/P）：你是提前做计划，还是最后一天
- 认知方式（S/N）：你看电影先看剧情还是先看镜头

## 六、验收标准（与前 5 篇不同）

| 指标 | 前 5 篇 | Day8 |
|---|---|---|
| 浏览 | ≥50 算好 | **≥30 算有效**（新结构，样本小） |
| 点赞率 | ≥10% | ≥10% |
| **评论区有真人字母串** | 从未出现 | **本篇唯一硬指标** |
| 收藏 | ≥1 | ≥1 |

**「评论区出现真人打的字母」是判断答题型结构是否成立的关键信号**——因为读者答完题就在图上，不需要跳转，互动成本最低。

## 七、内容配比建议（5:2:2）

| 类型 | 占比 | 作用 |
|---|---|---|
| **答题型** | **50%** | 引流 + 评论 |
| 对比型（INTJ vs INTP…） | 25% | 收藏 + 搜索 |
| 角色/观点型 | 25% | 涨粉 + 专业感 |

角色型**保留但降权**为「话题讨论型」——讨论「这类人」的共同特征，而不是逐个介绍角色。
