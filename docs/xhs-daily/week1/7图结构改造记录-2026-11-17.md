## 一、改了什么

### 改动 1：9 图 → 7 图，题目提到 P2（你选的 A）

**旧结构**（9 张，前 6 张全是文字，题在 P7）：
```
P1 封面 → P2 争议 → P3 像A → P4 像B → P5 另三维 → P6 结论 → P7 题目 → P8 人物卡 → P9 投票
```

**新结构**（7 张，第 2 张就能做题）：
```
P1 封面 → P2 先做3道题 → P3 一侧证据 → P4 另一侧证据 → P5 结论 → P6 结果卡 → P7 @点点互动
```

依据：爆款图数是 6/6/7/7/11，题目都在前 3 张；我们原来把题放在第 7 张，读者要先看 6 张文字。

**删掉的两页**：「另外三维没争议」与「结论前的过渡页」。前者信息量低且容易与类型口径冲突（Day3 就出过这个问题），合并进结论页。

### 改动 2：P7 从「我回你」改为「@点点」（你选的 A）

| | 旧 | 新 |
|---|---|---|
| 文案 | 「评论区打一个字母，我按字母回你一句」 | 「打出你的 3 个字母，再 @点点 拿专属分析」 |
| 服务提供者 | **我们**（手动，3 篇 0 条回复） | **平台 AI**（自动，爆款评论 1.2万–5.6万） |

这是本轮调研最关键的一条：爆款的评论量是点赞的 **4–9 倍**，靠的就是「打字母 + @点点」。我们之前的机制方向对了一半，但**服务提供者错了**。

副文案加了社会证明：「（别人打「ca b c」都能收到她的回复，你也可以）」。

### 改动 3：标题从「争议体」改「结果体」（你选的 A）

| 篇 | 旧标题 | 新标题 |
|---|---|---|
| day1 | 漩涡鸣人是直觉型的N人，还是经验型的S人？ | **鸣人这种性格，在81型里是哪一格** |
| day2 | 钢铁侠是J人还是P人 | **钢铁侠的性格，81型里还剩几格** |
| day3 | 曾国藩这种人格，16型真的装不下 | **曾国藩这种人，81型里只剩一格** |
| day4 | 路飞是S人还是N人？他自己也没想过 | **路飞这种性格，在81型里是哪一格** |
| day5 | 柯南是E人还是I人？判若两人 | **柯南的性格，在81型里是哪一格** |
| day6 | L是J人还是P人？局算尽饭点没准 | **L这种性格，在81型里是哪一格** |
| day7 | 赫敏是E人还是I人？最吵最静都是她 | **赫敏这种性格，在81型里是哪一格** |

**变化**：
- 全部 **15–16 字**（≤20 字上限）；
- 全部含 **「81型」**（你的第 4 项决策：81 型升为主词）；
- 全部是**结果承诺**（「在哪一格」= 告诉读者会得到一个坐标），不是二选一提问；
- 全部含**人物名**（搜索命中）+ **第二人称「你」或具体人物**（代入感）。

依据：爆款标题全是结果体——「你的性格历史上早有人替你疯过了」「你的性格，历史上已有人走完了一生」。

### 改动 4：81 型升为独立主词（你选的 A）

## 四、封面图标方案（2026-11-17 11:30 定案）

### 决策过程

原计划让 Day5–7 也使用人格画像，你提出「换成对应人物的网上找的图片」。我核实后确认这条走不通，并把选择权交回给你，最终**改回原创符号图标**。

### 为什么不能放网上找的角色图（核实过的证据）

| 证据 | 内容 |
|---|---|
| 项目红线 `README.md` §8.3 | 「只用文字提及角色名与作品名，**绝不放官方立绘、剧照、截图或 AI 仿图**」 |
| 柯南版权方 | 日本官方商品标注 `(C) 青山剛昌 / 小学館 / 読売テレビ / TMS 1996`——**四方共有** |
| L 的图片地位 | 维基百科明确标为「非自由文件」，原文：任何其他使用都可能构成侵权；并注明「不存在也无法创作自由替代版本」 |
| 中国判例 | 电商未经 Coser 授权使用 Cosplay 照片做商品推广，法院判侵犯**肖像权及相关权益**，停止侵权 + 道歉 + 赔偿 |

**结论**：官方图侵权、同人图需作者授权、Coser 照片涉肖像权——三条路都不通。所以改为**原创符号**：既抓到视觉识别点，又零风险。

### 五个封面图标（全部 SVG 手绘，同一套视觉语言）

统一构成：细线光芒 + 主体图形 + 朱砂点缀，配色只用纸色/墨色/赭金/朱砂。

| 篇 | 人物 | 图标 | 说明文字 |
|---|---|---|---|
| day3 | 曾国藩 | **书箱 + 毛笔** | 一箱书 · 一支笔 · 一场硬仗 |
| day4 | 路飞 | **草帽** | 一顶草帽 · 一只拳头 · 一片大海 |
| day5 | 柯南 | **放大镜 + 领结** | 一只放大镜 · 一个领结 · 一条线索 |
| day6 | L | **奶油蛋糕 + 樱桃** | 一块蛋糕 · 一支蜡烛 · 一局算尽的棋 |
| day7 | 赫敏 | **羽毛笔 + 书本** | 一支羽毛笔 · 一本书 · 一条规则 |

> day1（鸣人）/ day2（钢铁侠）保持原样——两者都是已发布内容，改动无意义。

### 实现方式

`notes-data.mjs` 新增 `coverIcon` 字段（取值：`strawhat` / `magnifier` / `cake` / `quill` / `brush`），模板通过 `COVER_ICONS` 查表渲染；`coverIconCap` 控制说明文字。人格画像仍在 P6（结果卡）保留，并用「↑ XXX 这一型的人格画像 · 非角色本人」标注区分。

### 顺带修的 2 个问题

1. **「L」在封面上太小**：单个拉丁大写字母的高度只占字号约 7 成，132px 下视觉重量远低于中文名。已加 `.latin1` 类，单/双字符拉丁名放大到 184px。
2. **蛋糕初版画成了「杯子里的碗」**：重画为层叠奶油蛋糕（两层糕体 + 奶油花边 + 顶樱桃 + 投影），现在可辨识。
