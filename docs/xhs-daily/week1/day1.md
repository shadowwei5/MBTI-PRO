## 正文（直接复制）

```
同一个人，上周测出 ENFP，这周变成 INFP。不一定是题坏了。

更常见的原因是：传统 16 型要求你在每个维度上二选一，可你本来就在中间。聚会里你确实喜欢热闹，加班那周你又只想一个人待着，两次都是真话。

我们把四个维度各拆成三档：E/A/I、S/B/N、T/C/F、J/D/P。中间那一档不是「没测出来」，是单独的一种状态。3×3×3×3，一共 81 种坐标，16 型之外还有 65 种。

比如 40 题里的第一道：「参加大型聚会后，我感到精力充沛、心情愉悦」和「参加大型聚会后，我需要独处一段时间来恢复精力」，很多人两个都想选。这套题允许你停在中间。

我们做这套档案，不是要给你换个更准的标签，是想把「卡在中间」那部分说清楚。

档案里给 ABCD「全能者型」配的主人物是曾国藩：书生带兵，用日记和家书自律，一生被概括成「结硬寨、打呆仗」。不是说他测过什么，而是「每一面都看得见、又不急着选边」这件事，在他身上有很具体的样子。

你是哪一维卡在中间？评论区聊聊，我们先来：E/I。

本内容仅供自我探索与娱乐参考，不构成心理诊断、医疗建议或招聘依据。MBTI-PRO 与 MBTI 官方机构无关联。
```
