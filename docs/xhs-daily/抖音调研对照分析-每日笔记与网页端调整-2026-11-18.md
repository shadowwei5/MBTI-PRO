## 一、每日笔记应该怎么发（回答第一个问题）

### 1.1 必须承认的事实：我们的笔记不是「答题型」

调研报告指出竞品（第 83 集「63 天 26 万单」）的笔记套路是 **「观点题 + 答题题」两种**，且**笔记本身就在答题**。

对照我们 5 篇已发笔记：

| 篇 | 内容形态 | 是答题型吗 |
|---|---|---|
| Day1 鸣人 | 讲人物争议 | ❌ |
| Day2 钢铁侠 | 讲人物争议 | ❌ |
| Day3 曾国藩 | 讲人物争议 | ❌ |
| Day4 路飞 | 讲人物争议 | ❌ |
| Day5 柯南 | 讲人物争议 | ❌ |

**我们从 Day1 到 Day5，做的全是同一种「人物争议科普」。** 从未让读者在笔记里动手。

而上一轮复盘已经证实：读者不答题，就不会想知道结果 → 不会评论 → 系统判定低质 → 降流量。这是同一个问题的两面。

### 1.2 但「答题型笔记」不是把 P2 搬到第一张图

关键区别：

| | 我们现在的 P2 | 竞品的答题笔记 |
|---|---|---|
| 读者要做什么 | 读完两段描述，选 A/B/C | **立刻做题，立刻得到结果** |
| 有无结果反馈 | 无（要跳到网站才知道） | **有**（题末就告诉你属于哪一档） |
| 互动成本 | 高（要自己跳走） | **低（评论区打 3 个字母）** |

所以真正的答题型笔记结构应该是：

```
P1 封面（问题式钩子）
P2 第 1 题 + 三档选项
P3 第 2 题 + 三档选项
P4 第 3 题 + 三档选项
P5 你的 3 个字母 = 哪一档（对照表）
P6 人物对应（这个角色属于哪一档）
P7 引导：评论区打字母，@点点 拿分析
```

**「读者能当场做完并得到结果」是核心，题在第几张图是次要的。**

### 1.3 每日发布节奏：从「日更一人物」改为「日更一题」

**这是我建议的最大改动。**

| | 现在 | 建议 |
|---|---|---|
| 每日主题 | 一个虚构角色（鸣人/钢铁侠/曾国藩…） | **一个能当场做的测试题**（3 道题 → 3 档结果） |
| 角色出现位置 | P1 封面大字 | **P6**，作为「这道题谁最典型」的锚点 |
| 标题 | 「XX 的性格，在81型里是哪一格」 | 「3 道题，测出你回完消息要不要缓半小时」 |
| 互动 | 评论区打字母（要跳网站） | **评论区打 3 个字母（已在图上做完）** |

**为什么这样更好**：
1. 直接命中「人们关心的问题」（报告第 83 集原话：「关键在于找到人们关心的问题」）
2. 每日产出**可复用的答题素材**，而不是消耗一个角色
3. 角色从「主角」降为「素材」，解决了角色同质化（我们已经在用漫威/动漫/哈利波特，离 IP 太近）
4. 「81 型」自然出现在结果对照表里，不生硬

### 1.4 但必须保留 5:1 的配比

报告第 49 集给的笔记配比是：**产品内容 + 话题讨论 + 互动引导**。

**建议配比**：

| 类型 | 占比 | 例子 | 目的 |
|---|---|---|---|
| **答题型** | **50%** | 3 题 → 3 档，打字母 | 引流 + 评论 |
| 对比型 | 25% | 「INTJ vs INTP 差在哪」「E 人和 I 人的三种混搭」 | 收藏 + 搜索 |
| 角色/观点型 | 25% | 保留现在的曾国藩、名人人格 | 涨粉 + 建立专业感 |

**注意**：角色型笔记继续保留，但**必须降权为话题讨论型**，即讨论「这类人」的共同特征，而不是逐个介绍角色。

### 1.5 立刻可执行的第一篇（答题型样板）

用我们已有的 E/I 维（争议最热、题库最全）：

**标题**（3 个备选，需你选）：
- A. `3 道题，测出你回完消息要不要缓半小时`（公式 #75 至关紧要的头 N 分钟）
- B. `群聊里最安静的，是话最多那个人吗`（公式 #72 敢不敢测一测）
- C. `回完消息要缓半小时的人，其实分三种`（公式 #26 数字锚定）

**7 图结构**：
```
P1 封面：三档结果直接列出（现场就开口 / 看场合切换 / 先观察再融）
P2 第 1 题（原题 #1：大型聚会后…）
P3 第 2 题（原题 #6：团队讨论中…）
P4 第 3 题（原题 #20：通过交流理清想法…）
P5 对照表：你的 3 个字母 → 你属于哪一档
P6 角色锚点：柯南属于哪一档 + 为什么
P7 引导：打出 3 个字母，@点点 拿专属分析
```

**注意**：P5 的对照表就是上次做废掉的「坐标条」的正确用法——它不是「81 型的坐标」，而是**读者自己的结果**。这才是可存的东西。

### 1.6 保留现有发布纪律（这些是对的，别改）

- 20:30–21:30 发布（虽然时段不是主因，但保持可比）
- 位置不填
- 商品卡可选（**但建议从明天起挂上**，见 §三）
- 发布后 10 分钟内发置顶评论
- 置顶评论必须引导 @点点，不能自己给答案

## 二、网页端测试内容要不要调整（回答第二个问题）

### 2.1 商业模式前提（用户确认，2026-11-18）

**小红书付费购买 → 获得兑换码 → 网页输入兑换码 → 全部内容免费解锁。**

| 交付形态 | 决定 |
|---|---|
| 网页报告 | **兑换码 = 全部解锁**，不设二次付费 |
| PDF | **不产出**。只产出**海报**（3:4 分享图） |
| 邮箱 | 不作为交付渠道 |

这条前提决定了下面几件事：
- **报告里「PDF 下载」的建议不适用**，且 `server/src/services/reportPdf.ts` 这个已实现的 PDF 服务在当前模式下是死代码（**不删除**，因为兑换码模式里仍可能有用；但不再投入）
- 免费层的价值更高了：**用户输入兑换码前看到的每一句，都是转化依据**
- 交付说明页仍然必要——但内容是「怎么用兑换码 + 怎么用海报」，不是「怎么收 PDF」

### 2.2 必须先纠正报告的一个事实错误

报告说「PDF 下载（你 PRD 里 P2 已有此项，一直没做）」。

**实际上 `server/src/services/reportPdf.ts` 已经实现了完整的 PDF 生成**（256 行），`email.ts` 也已接入——但既然当前模式是「只出海报」，**PDF 不再是待办项**。这条建议直接作废。

### 2.2 真正的问题：线上未付费时，用户几乎什么都看不到

我实测了线上 API（`https://mbti-pro.com/api/results/ESFP`）：

| 字段 | 未付费时长度 | 说明 |
|---|---|---|
| `summary` | **91 字** | 唯一可见内容 |
| `overview` | 0 | 空 |
| `eiModule` / `snModule` / `tfModule` / `pjModule` | **全 0** | 4 个维度模块全空 |
| `strengths` / `growthAreas` / `careers` | **全 0** | 全空 |
| `celebrities` / `celebrityStories` | 空 | 空 |
| `paid` | false | — |

**即：免费用户点进结果页，只能读到一句 91 字的简介。**

### 2.3 更严重：付费入口在某些路径下根本不显示

`ResultView.vue` 第 249 行：

```vue
<AccessGate v-if="hasTestData && typeData && !paidReport" ... />
```

而 `hasTestData` 的定义（第 31 行）：

```ts
const hasTestData = computed(() => !!route.query.scores)
```

**结论**：如果用户**不是从答题流程跳过来**（例如直接访问 `/result/ESFP`、或从笔记里点链接进来），`hasTestData = false` → **AccessGate 不渲染 → 用户看不到任何购买入口**。

这是一个**真实的付费转化断点**，而且和报告说的「0.99 元心理价位偏低」是两个不同的问题——**在讨论该不该涨价之前，得先保证想买的人能看到购买按钮**。

### 2.5 关于定价：建议小步验证，不要一次跳到 8.9

报告建议「0.99 引流 + 8.9–29.9 利润品」。**方向我同意，但直接改价风险大**，原因：

1. 报告自己也引用了评论「这种免费一大堆，谁去付费，0.19 才可能」——说明**用户觉得 0.99 不值**，但这话也可能只是「便宜没好货」的惯性怀疑，不能直接当定价依据
2. 报告第 49 集的对标案例是**「活动价 8.9 元，累计 6800 份」**，那是**活动价**不是日常价，且该店有 1500 粉
3. 我们目前**零成交、零好评**。在没有任何成交样本的情况下涨价，等于同时改了两个变量
4. **退款风险**：0.99 元主观退款是大概率事件（报告也提到）。涨价能减少退款，但也更考验交付质量

**我的建议（三步，不跳级）**：

```
第 1 步（本周）  保持 0.99，先把购买入口修好（P0）+ 免费层加内容
                  → 目标：跑出第一批真实成交 + 好评截图
第 2 步（10 单后）上 1.9–2.9 元「81 型完整解析报告」
                  → 验证价格接受度，同时看退款率
第 3 步（30 单后）拆 SKU：16 个单人格成长手册 + 合集
                  → 这时才谈 8.9–29.9 的阶梯
```

**同时**：报告提到的那条「单人格成长手册」思路，其实**我们的 324 段文案不用重写**，只需重新包装——这与「81 型」差异化方向一致，是对的。
