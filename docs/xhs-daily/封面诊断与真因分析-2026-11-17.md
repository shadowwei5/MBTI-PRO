## 二、我之前的判断错了：不是时段问题

上一轮我判定「时段是主因」，理由是前三篇都没按晚高峰发。**Day4 按 20:27（标准晚高峰）发了，浏览 12，全系列最低。**

**时段假设被证伪。**

同时注意另一件事：**点赞率始终在 6.5%–9.5%**，属于正常偏上。这说明——**点进来的人，是认可的。**

浏览掉、点赞率不掉 = **问题在「有多少人看到」，不在「看到的人觉得好不好」。**

## 三、浏览单调递减说明什么

```
11-13 → 77
11-14 → 61
11-15 → 21
11-16 → 12
```

四天单调下降，**且与内容质量无关**（点赞率没掉）。这是小红书新号最典型的一条曲线：**新号前几条有流量扶持，扶持用完后回落到真实权重。**

再看一个数据：前两篇**收藏 0、评论 0**。小红书的推荐逻辑里，收藏和评论是比点赞更重的质量信号。**两条高浏览笔记零收藏，等于向系统证明「这个账号的内容没人想存」**——第三、四篇的流量池因此被压低。

**所以：内容不是不难看，是「不值得存」。**

## 四、封面诊断：这是真正的病灶（逐张对比）

我把 5 张爆款封面下载下来，和我们的封面放在一起看。差异是**结构性的**，不是美观程度。

### 4.1 爆款封面长什么样

**① 1.4 万赞《你的性格历史上早有人替你疯过了》**
- 整个封面只有 **1 句话**，分 3 行，字号占画面宽度 75%
- 底色：浅蓝，纯色，无纹理
- 唯一装饰：给「性格」两字加**黄色荧光笔**高亮
- **没有**：账号名、栏目名、页码、题数、时长、维度说明
- 左上角只有一个引号符号，右下角一个色块

**② 9003 赞《有些性格，迟早会走到更高的位置》**
- 标题「**十大天赋**」四个字占满顶部，字号极大
- 下面 **10 个图标排成网格**，每个配一个词（语言天赋、音乐节奏、逻辑算数、空间天赋、人际交往、自我认知、身体动觉、美学感知、自然观察、创意创新）
- **封面直接展示了「你会得到什么」**——10 种结果全在封面上，读者立刻对号入座
- 每种图标有不同浅色背景块（粉、黄、蓝、绿、紫）

**③ 1.1 万赞《超准！一分钟测出你的本命香》**
- 主文案「一分钟测出 **「你的本命香」**」，用引号强调核心词
- 副标题英文一行
- 底部 4 行小字（情绪化的文案，不是功能说明）
- 背景：薄荷绿的水彩/烟雾质感，非常柔和

**④ 1219 赞《测测你骨子里是天使还是恶魔》**
- 上方蓝色圆：「天」+「守护者」
- 中间大字「**你骨子里 是天使还是恶魔？**」，天使蓝、恶魔红分色
- 下方红色圆：「魔」+「真性情」
- **底部列出 4 种结果**：纯天使 / 天使外表恶魔内心 / 恶魔外表天使内心 / 纯恶魔
- 还有一行：「**6 道题，测出你隐藏的那一面**」

### 4.2 我们的封面（Day3 曾国藩）

- 左上角：`MBTI — PRO`（品牌）
- 顶部横条：`PERSONALITY ARCHIVE / COVER` + `01 / 09`（栏目名 + 页码）
- 左侧：`01 / COVER`（二级页码）
- 人物名「曾国藩」+ 别名「曾国藩 · 晚清名臣 · 湘军之父」
- 钩子「狠了一辈子 / 却没几个人懂他」
- 右侧：人格画像 + 「四维全部居中 · 81 型里的全能者」
- 底部：`争议维 · 03 决策方式` + `40题 / 6-8分钟 / 81型` 信息条
- 页脚：`81-TYPE PERSONALITY ARCHIVE` + `NO.03`

### 4.3 差异清单（这是关键）

| 维度 | 爆款 | 我们 | 影响 |
|---|---|---|---|
| **主文案占画面比例** | 60–80% | 约 35% | 缩略图里字太小，看不清 → 不点 |
| **栏目名/页码** | **完全没有** | 3 处（顶部横条、01/COVER、NO.03） | 浪费 20% 版面，且像内部文档 |
| **展示结果** | **封面就列出 4–10 种结果** | **0 种** | 读者不知道能得到什么 → 没有期待 |
| **题数表述** | 「6 道题」 | 「**40 题** 6-8 分钟」 | 40 比 6 大 6.7 倍，劝退 |
| **色彩** | 浅蓝 / 薄荷绿 / 粉蓝撞色 | **米黄 #F2EDE3** | 与信息流背景接近，不跳出来 |
| **装饰** | 荧光笔高亮、圆形色块、图标网格 | 细线、留白、衬线字体 | 像 PDF 报告，不像互动帖 |
| **动作词** | 测测 / 敢不敢 / 你会 | 我们的钩子是陈述句 | 缺少「叫你参与」的指令 |

### 4.4 一句话概括

**我们做的是「书封」，爆款做的是「海报」。**

书封的逻辑是「我有格调，你进来慢慢读」；海报的逻辑是「三秒内让你知道你会得到什么，现在就来」。

小红书信息流是**竖版缩略图 + 极快滑动**，书封在这种场景里必输。

## 五、为什么收藏是 0（这条最伤）

爆款 9003 赞那篇的封面是「十大天赋」的**结果网格**——它天生就是「值得存下来对照」的东西。

我们的封面没有任何「可存」的东西：没有清单、没有对照表、没有分类图。看完就完了。

**系统读到「零收藏」，判定低质，减少下一批推荐。** 这就是浏览单调下降的机制闭环。

## 六、今天要做什么（结论）

### 🔴 必须改的：封面（这次改结构，不是改配色）

具体三条：

1. **删掉所有「文档元素」**：`MBTI — PRO`、`PERSONALITY ARCHIVE`、`01 / 09`、`01 / COVER`、`NO.03`、`81-TYPE PERSONALITY ARCHIVE` 全部从封面移除。
2. **主文案放大到占宽 70%+**，只留 1–2 行，用一个荧光色块高亮关键词。
3. **封面直接展示结果分类**：把该维度的三档（如 E / A / I）画成 3 个色块 + 一句话描述——这是「可存」的东西，也是对号入座的钩子。

### 🟡 顺带改的：题数表述

「40 题 · 6-8 分钟」→ 「**先做 3 道，看你在哪边**」（我们的 P2 确实有 3 道，是实话），完整 40 题只在正文里说。

## 八、我这次的失误（记下来）

1. **连续 4 轮做小红书内容，从没看过一张爆款封面。** 只看标题和正文，等于只研究了 20% 的变量，而封面是点击率的决定性因素。
2. **把「时段」当成主因**，还在上一轮把它写进验收标准。Day4 晚高峰发布后数据更差，证明这个假设是错的。
3. **一直在优化「阅读体验」（档案感、引文、坐标条），却没优化「三秒决策」。** 越做越像一份精致的报告，离「刷到就想点」越来越远。
