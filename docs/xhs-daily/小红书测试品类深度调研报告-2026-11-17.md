## 三、爆款的四个共同点（逐篇深读得出）

### 3.1 标题公式：疑问 / 断言 + 身份标签

实测高赞标题（按赞数）：

| 赞 | 标题 | 公式拆解 |
|---|---|---|
| 1.4万 | 你的性格历史上早有人替你疯过了 | 第二人称 + 断言 + 悬念（没说答案） |
| 1.1万 | 超准！一分钟测出你的本命香～ | 强断言 + 时间承诺 + 具体对象 |
| 8976 | 有些性格，迟早会走到更高的位置！ | 泛化群体 + 正向许诺 |
| 5653 | MBTI的怪癖 | 人群标签 + 反常词 |
| 5183 | sdfj人格测试🔥我居然是严浩翔谁懂啊! | 具体结果前置 + 情绪 |
| 3964 | MBTI最恐怖第一名：INFJ | 排行 + 第一名 + 悬念 |
| 2822 | 测测你前世是哪种妖怪 | 动词开头 + 猎奇题材 |
| 2088 | 测试：你是J人还是P人 | 冒号 + 二选一 |
| 1680 | 测测你身上的姐感和妹感哪个更重 | 动词 + 新造概念 + 二选一 |

**共同点**：
- **第二人称「你」出现率极高**；
- **至少给一个具体对象**（历史人物 / 本命香 / 妖怪 / 姐感妹感），不给抽象概念；
- **承诺「一分钟 / 几道题」**，不承诺「深度」；
- **新造词优先**（姐感妹感、本命香、危险人格、妖怪转世）——新词没人搜但没人竞争。

### 3.2 图片结构：3–7 张，最后一页是「结果分类表」

实测图数：

| 图数 | 笔记 | 赞 |
|---|---|---|
| 3 | 你该换工作，还是换活法？ | 17 |
| 6 | 你的性格历史上早有人替你疯过了 | 1.4万 |
| 6 | 测测你身上的姐感和妹感哪个更重 | 1680 |
| 7 | 测测你骨子里是天使还是恶魔？ | 1216 |
| 7 | 测测你前世是哪种妖怪 | 2822 |
| 11 | 超准！一分钟测出你的本命香～ | 1.1万 |

**关键发现**：**不是 9 张，而是 6–7 张**（图多的那个是 11 张，内容是「结果分类全表」）。我们的 Day1–7 全是 9 张，**偏多**。

结构上，爆款是：
```
P1 封面（钩子）
P2-P4 几道测试题（让读者当场能做）
P5-P6 结果分类（A 型是…、B 型是…）
P7 完整版入口 / 引导
```

**和我们的结构差异**：我们的 9 张是「封面 → 争议 → 正反证据 → 结论 → 题目 → 人物卡 → 投票」，**题在 P7，太靠后**。爆款的题在 **P2 就出现**。

### 3.3 互动爆发点：评论区「字母串 + @点点」

实测：6 篇爆款里 4 篇的评论区形态是——

```
用户: cabcd
用户: bacbadddaa
用户: BADDDC
用户: @点点
```

**读者在评论区打出自己每道题的选项字母，然后 @点点（小红书官方 AI）生成分析。**

这是**这轮调研最重要的发现**：

| | 传统做法 | 爆款做法 |
|---|---|---|
| 读者要做什么 | 打字描述自己 | **打几个字母** |
| 谁给回复 | 作者手动（慢、易断） | **平台 AI 自动** |
| 评论量级 | 几十 | **1.2 万 ~ 5.6 万** |

对比数据：
- 「你的性格历史上早有人替你疯过了」：赞 1.4 万 / **评 5.6 万**（评论是点赞的 4 倍）
- 「测测你前世是哪种妖怪」：赞 2822 / **评 2.6 万**（9 倍）
- 「测测你身上的姐感和妹感」：赞 1680 / **评 1.2 万**（7 倍）

**评论量远超点赞量**，这是测试类内容的独有特征——因为「打字母」成本极低，且打完之后平台 AI 会给一段专属分析，**每个人都能得到一次「被回应」的体验**。

> 我们现在 P9 的「评论区打个字母」方向是对的，但**只做到了一半**：没告诉读者「打完可以 @点点 拿分析」。这是我们评论区至今 0 条真实回复的直接原因。

### 3.4 卖的是「标签」，不是「报告」

三篇拆解笔记口径一致：

> 「买家掏这一块钱，大多不是为了做题，而是为了**测完发出去晒**。」

> 「用户买的不是科学诊断，而是一次**便宜、好玩、可以保存和分享的自我表达**。」

> 「大家愿意买，是因为**主角是自己**：我像谁、我出生那晚、我怎么长大的。」

**这直接冲击我们的产品定位**：MBTI-PRO 卖的是「81 型完整档案报告 + 四维深度解析 + 人物解读」，**是一份「长报告」**。而爆款卖的是「**一张结果卡**」。

报告不是不能卖，但**不能当主卖点**。报告是留存和口碑，标签卡是获客。

| 事实 | 数据 |

**结论：MBTI 是红海，且「跟风只能分到零头」。** 我们账号叫「Shadow奇思妙想」，做的是 81 型——**本质仍是在 MBTI 这个红海里**。

但同时：**「81 型」是现成的新概念**。站内搜「81型人格」，除我们之外几乎无人做（此前实测：搜「81型人格」出来的多是生命数字、联合码，与 MBTI 无关）。

**这是我们的真实机会：把「81 型」当作一个独立的新题材去打，而不是当作「更准的 MBTI」。**

## 五、对我们项目的 9 条具体启发

### 🔴 高优先级（直接影响下一批内容）

**启发 1：标题从「争议体」改为「结果体」**
- 现在：`路飞是S人还是N人？他自己也没想过`（争议，不承诺结果）
- 爆款：`你的性格历史上早有人替你疯过了`（承诺「你会得到一个身份」）
- **改法**：标题里给一个**具体的结果想象**。例如「你的性格，在 81 格里是哪一格」比「你是 S 人还是 N 人」更接近爆款结构。

**启发 2：图数从 9 张减到 6–7 张，题目从 P7 提到 P2**
- 爆款图数：6 / 6 / 7 / 7 / 11，我们的 9 张偏多且题在 P7
- **改法**：`P1 封面 → P2-P4 当场能做的小测（3 道）→ P5-P6 结果分类 → P7 完整版引导`
- 这样读者**在第 2 张图就能开始玩**，而不是看 6 张文字才见到题。

**启发 3：P9 加一句「@点点 帮你分析」**
- 现在：`在评论区打一个字母，我按字母回你一句。`（依赖作者手动，我们 3 篇评论全是 0）
- 爆款：`打出你的选项 @点点`（平台 AI 自动回，评论量 1.2万–5.6万）
- **改法**：`打出你的 3 个字母，@点点 会给你一段专属分析`
- **这是投入产出比最高的一条**：零成本，直接复用平台已有能力。

**启发 4：标题加「自动发货」类信任词（如果恢复卖货）**
- 数据：标「自动发货」的 14 个测试，销量中位数 **2,595**；整体中位数 **113**。**差 23 倍。**
- 我们现在是「个人售卖」，交付靠兑换码，**这条路可以标**。

### 🟡 中优先级（影响产品与定位）

**启发 5：把「一张可晒的结果卡」做成核心交付物**
- 现在的主卖点是「81 型完整档案报告」
- 爆款逻辑是「**一张标签卡**」——可保存、可发朋友圈、可对比
- **改法**：产品里把「结果卡/分享海报」提到第一屏，报告退为「深入了解」。我们已有 `/api/mediums` 和分享海报能力，**成本很低**。

**启发 6：题材用「81 型」独立打，不叫「MBTI 进阶版」**
- MBTI 有 19 家在打，平均不到 1500 份
- 「81 型」几乎无人占位
- **改法**：标题与标签里，「81型」作为**主词**出现，而不是副标题。

**启发 7：结果要「新造词」，不要「16 型原名」**
- 爆款全是新词：姐感妹感、本命香、危险人格、妖怪转世
- 我们用的是「竞选者型 / 战略家型 / 全能者型」——**这些是 16 型体系的衍生，不够新**
- **改法**：81 型可以有自己的「标签名」，例如按四维居中程度起名（全能者 / 边界者 / 钟摆者…），做成一套**专属词汇**。

### 🟢 低优先级（观察项）

**启发 8：避开「深度」这个词**
- 所有爆款都不承诺深度，都承诺「一分钟 / 几道题」
- 我们的 P1 信息条写「6-8 分钟」——**其实偏长**，建议改「3 分钟出结果」（如果产品允许先给简版）

**启发 9：题材池的扩展方向**
从站内已验证的题材看，可迁移到 81 型的方向：
- 历史人物（11.5 万单，最验证）→ **我们已有 317 位代表人物，这是现成资产**
- 妖怪/前世（2822 赞）→ 需要新造
- 本命香/气味（1.1 万赞）→ 跨感官，不适合我们
- 职场/生活方式（3273 赞）→ **可做：81 型 × 你适合哪种工作节奏**

## 六、我最想说的一句

**这轮调研推翻了我此前的一个判断。**

我一直在优化「内容深度」——把人物争议写得更细、加引文、加坐标条。但数据显示：**卖得最好的测试，内容深度都很浅**，浅到「6 张图 + 几张结果卡」。它们赢在：
1. 让人**当场就能玩**（题在 P2，不在 P7）
2. 让人**打完字就能得到回应**（@点点，不用等作者）
3. 给的是**一个能晒的标签**，不是一份分析

**我们做的 81 型内容比它们「好」，但不在同一个游戏里。** 我们的内容适合「已经对 MBTI 感兴趣、愿意读 6 分钟」的人；而爆款面向「刷到就想测一下」的人——后者是 100 倍大的池子。
