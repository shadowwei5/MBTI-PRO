## 2. 阻断项（P0，6 项，改完才能投放）

### B1｜顾城：不该出现在「悠然者型」名单里

- **位置**：ABFP 悠然者型，第 4 位（`types.ts` 的 `CELEBRITY_MAP.ABFP`）。
- **问题**：顾城是杀妻后自杀的暴力犯罪加害者。把它放在「悠然者型 / 乐天闲适」的性格类比里，是**价值事故级**的选人错误——用户只要认识顾城，整份报告的可信度立刻归零；被截图放到小红书，是一次无法解释的公关问题。
- **改法**：从 ABFP 移除，替换为「丰子恺」（画家 / 散文家，悠然、日常审美，四维对得上）或「王维」（唐代诗人，山水田园，更古典）。**优先丰子恺**：与悠然者型的「在日常里找趣味」最贴。
- **同步**：新名字必须补进 `server/src/content/celebrity-fields.ts`（身份写「画家 / 散文家」或「唐代诗人」），否则结果页会显示「公众人物」。
- **验收**：`grep -n "顾城" server/src/content/*.ts` 无结果；ABFP 仍是 4 位且身份非空。

### B2｜扁鹊：《史记》写成《韩非子》

- **位置**：ISFD 关怀者型 · 生平：「以望闻问切和早期诊断闻名，**《史记》记载他见蔡桓公的故事**。」
- **问题**：出处张冠李戴。「扁鹊见蔡桓公」出自**《韩非子·喻老》**；《史记·扁鹊仓公列传》记的是「扁鹊过齐，**齐桓侯**客之……望桓侯而还走」。付费内容里出现这种可一查即证的出处错误，是最伤专业感的一类瑕疵。
- **改法**：「以望闻问切和早期诊断闻名，《韩非子》记载他见蔡桓公的故事；《史记》记载他望齐桓侯而退。」（两句都保留，损失为零，还多一个出处）
- **验收**：改后文中不再出现「《史记》……蔡桓公」连写。

### B3｜马丁·路德·金：时间对不上

- **位置**：ENFD 鼓舞者型 · 生活态度：「39 岁遇刺身亡，**他推动的民权法案在一年前刚刚通过**。」
- **问题**：事实错误。1964 年《民权法案》、1965 年《投票权法》，金 1968 年 4 月 4 日遇刺——不是「一年前」。他遇刺时国会里正在搁置的是 1968 年《公平住房法》，该法在他死后一周（4 月 11 日）通过。
- **改法**（任选，推荐第二种，更有力）：
  - ①「1964 年《民权法案》与 1965 年《投票权法》先后通过，1968 年他遇刺时《公平住房法》还在国会搁置。」
  - ②「1968 年他遇刺时，《公平住房法》正卡在国会——一周后法案通过，他没能看到。」
- **验收**：`grep -n "一年前刚刚通过" server/src/content/life-advice.ts` 无结果。

### B4｜7 个型的「经验教训」写的是死讯，却接「把教训写进日常节奏」

- **位置**：`life-advice.ts` 的 `LIFE_ADVICE[code][1]`（经验教训素材）+ 固定连接句 `LENS.pj`。命中的 7 个型：

| 类型 | 现在写的是 |
|---|---|
| ENFD 鼓舞者型 | 39 岁遇刺身亡，他推动的民权法案在一年前刚刚通过（含 B3 的问题） |
| ISCJ 慎行者型 | 他最终死于权臣案牵连，八表与天文志由妹妹班昭续完 |
| ISCP 巧手型 | 他因卷入宫廷斗争被迫自尽——发明家的个人结局，不代表发明会失传 |
| IBCP 求知者型 | 39 岁死于肺结核，葬礼上按遗愿把那只银杯里的泥土撒进墓穴 |
| ASCD 稳健者型 | 夺门之变后以「意欲」二字被杀，抄家时家无余财 |
| ANCJ 设计者型 | 他晚年受邀去瑞典教女王哲学，五个月后因清晨授课的严寒离世 |
| ENTD 战略家型 | 三十二岁死于巴比伦，帝国随即被部下瓜分——组织比征服死得慢得多（较轻，素材本身带结论） |

- **问题**：读出效果是「他死了。把教训写进日常节奏，它才不会在下一次重演。给你的建议：……」——**句间逻辑断裂**，付费用户会一眼看出是模板拼的（尤其 B4 的第 1、2、4 条）。
- **改法**：素材**不用动**（这些都是动人且可查的史实），只把固定句 `LENS.pj`（「把教训写进日常节奏，它才不会在下一次重演。」）替换成按素材收束的一句，例如：
  - ISCJ →「把未完成的部分交给能接着做的人，是这类长期工程的最后一环。」
  - ISCP →「发明会留下来，发明者的处境不会——这两件事要分开算。」
  - IBCP →「把有限的力气收束到一件事上，这件事才可能穿过你的一生。」
  - ASCD →「守住原则之前，先想清楚代价由谁承担、能承担多久。」
  - ANCJ →「再好的方法，也要配一副撑得住它的身体。」
  - ENFD →「把目标写进制度，比赢得一次道义胜利更难，也更长久。」
  - ENTD →「扩张要给结构留出生长的位置，否则帝国比人先死。」
- **验收**：这 7 个型的 `pjModule` 不再出现「把教训写进日常节奏」；且每条读起来「素材 → 结论 → 建议」逻辑通顺（人工读一遍即可）。

### B5｜付费正文有「草稿感」，且与「四维」口径不符（本轮工作量最大的一项）

这不是一条文案问题，是四个问题叠在一起，**平均 353 字的付费正文里有 101 字（28.6%）是 81 个型完全相同的句子**：

| 现象 | 实测证据 | 用户观感 |
|---|---|---|
| ① 每条都带编辑标签 | 页面直接渲染「**【生平】**曾国藩（晚清名臣）书生带兵……」「**【看世界的方式】**……」 | 像未清理的大纲/草稿 |
| ② 人名 + 身份重复 | REFERENCES 行已展示「曾国藩 / 晚清名臣」，DEPTH 第一条又以「曾国藩（晚清名臣）」重开一遍 | 排版冗余 |
| ③ 四句连接句全库同一份 | `life-advice.ts` 的 `LENS` 常量（101 字）被拼进全部 81 型 | 测两次或和朋友对一下，立刻发现是模板 |
| ④ 行标签与内容不对应 | 「能量来源」放的是生平前半段、「认知方式」放的是生平后半段、「生活态度」放的是死讯/结局 | 标着「四维分析」，其实是人物小传 |

- **改法（本轮做 ①②③④-a，方案 A）**：
  1. **去掉 4 个【】前缀**（`【生平】`/`【看世界的方式】`/`【关键抉择】`/`【经验教训】`），行标签已经表达了同样信息；同时去掉 ei 条开头重复的「人名（身份）」。
  2. **修全角空格**：`。 给你的建议：` → `。给你的建议：`（4 处拼接模板统一改）。
  3. **替换 101 字固定句**：按「素材类型 × 维度」给 12–20 个变体池，按型分配且同一型的 4 句互不相同；验收线：**任意两个型之间不得出现 ≥15 字完全相同的句子**（标签词、收尾短语不算）。
  4. **口径对齐（方案 A，推荐本周做）**：区块标题「04 / DEPTH 四维深度解析」→「**04 / DEPTH 代表人物解读**」，四行标签改为「起点与志向 / 看世界的角度 / 关键抉择 / 代价与教训」；同时把商品页与小红书文案里「四维深度解析」的说法改为「**由代表人物的生平与关键抉择写成的四条建议**」——这与 `docs/xhs-shop/shop-cards.html` 现有文案本来就一致，属于把页面追平文案，工作量最小、最诚实。
  5. **方案 B（真四维，本轮不做）**：324 条重写为「该维度定义 + 主人物在该维度上的表现 + 建议」，3–5 人天。**建议排在提价或转化验证之后**，现在 0.99 元不需要也不值得。
- **验收**：任一型正文中不再出现【】；跨型重复句检测为 0（见 Y8 脚本）；商品页/小红书/结果页三处说法一致。

## 3. 建议项（P1，8 项）

### Y1｜「认知方式」的固定句和 S 型定义自相矛盾

现文：「看清局面靠的不是收集更多信息，而是知道什么可以不看。」——但「S 实感 / B 均衡」这一维的定义就是**依赖具体信息与经验**，至少在 ABTP（达尔文「先让证据说话」）、ISCD（宋应星「记录匠人经验」）、IBTP（孟德尔「先记录数据」）、ASFD（宋慈「固定证据链」）、ISTJ（巴菲特「先看事实与账目」）这 5 个型里，素材和这句连接句**正相反**。与 B5-③ 一并替换：认知方式这一维的连接句要分 S/B/N 三档写（S 档必须在「信息」上正面说，不能否定收集信息）。

### Y2｜引言策略（答复交接文档 5.1）：选 ①，维持现状

- **理由**：结果页 `ResultView.vue` 的引言是 `v-if="featuredProfile.quote"`，没有引言时**不渲染空行**，不存在版式空缺；「不编造名人名言」的价值高于 81 型版式统一。补引言（②）需要 80 位可查原话，成本与风险都最高；取消引言改定位句（③）要新写 81 条，且会把「有出处」变成「又一句模板」。
- **唯一要补的**：ASTJ 孔子那句「学而不思则罔，思而不学则殆。」**补出处**——「——《论语·为政》」。这是目前全库唯一一条引言，没出处的收益为零、风险为正。

### Y3｜流行角色（答复交接文档 5.2）：不要硬凑，只补 3 个高频型

- **总判断**：不为了「每型都有角色」而塞人。测出 ANCD 哥德尔 / ANCJ 笛卡尔 / INTD 康德 / INCP 拉马努金的人，看到维特根斯坦比看到鸣人更满足；硬塞会同时得罪两边。
- **但**：16 个传统型里 **INTJ、ESTP、ENFJ 三个没有流行角色**，而这三个恰好是 15–35 岁在中国互联网语境里最容易被测到、最爱截图传播的类型。**优先只补这 3 个**：

| 型 | 现名单 | 建议补位（需按项目规则复核四维后再定） |
|---|---|---|
| INTJ 建筑师型 | 尼采 / 马斯克 / 曹操 / 诸葛亮 | 罗辑（《三体》）——目标—系统—长期主义；或 埃尔文·史密斯（《进击的巨人》） |
| ESTP 企业家型 | 迈克尔·乔丹 / 李小龙 / 成龙 / 埃尔文·约翰逊 | 樱木花道（《灌篮高手》）——临场、身体、竞争心；注意与 ISFP 的流川枫同作品不冲突（规则是人物唯一，不是作品唯一） |
| ENFJ 主人公型 | 奥巴马 / 奥普拉 / 曼德拉 / 蔡元培 | 欧尔麦特（《我的英雄学院》）——激励他人、承担象征 |

- **同步**：三位都要进 `scripts/pop-culture-reps.json`（否则审核表不标「流行」，`normalize-pop-order.mjs` 也不会把它排到第 2 位）。
- **ESFJ 的两人问题**：ESFJ 现有灶门炭治郎（第 2 位）+ 安娜（第 3 位）两位虚构角色，与项目自己写的「一个型只放一位」规则冲突（`normalize-pop-order.mjs` 遇到 2 个会跳过，属「人工决定」）。**结论：保留两位，把规则改成「最多两位，且排在第 2–3 位」并写进文档**——安娜对 ESFJ 的匹配度很高，删掉是损失；规则应服从内容，而不是反过来。

### Y4｜边界人物（答复交接文档 5.3）：全部保留，但立三条红线
